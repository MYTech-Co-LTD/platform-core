# duckle-native-first：原生优先的判停门

## 定位（先读）

- 本 skill 是**流程执法器 + 指针**，不是第二事实源。三档判据、证据强度排序、E3 证成方法学都在
  正典 `docs/data-platform-handbook.md`（§1.1 / §1.1.1）；引擎能力清单在 `duckle/README.md` §7。
  本文件只回答一件事：**你有没有先问过引擎。**
- 正典与本 skill 冲突时**正典赢**，并当场回来改本文件。
- **为什么有它**：#917（2026-10-19）——对账子管线手搓了一份「净销售额」口径，而同一环境里
  `src.postgres`（读物化结果）、`qa.reconcile`（原生源↔目标对账）、`routines/`（可被 `routineRef`
  引用的保存 SQL）**都在**。没人查目录 ⇒ 那份手搓的实现与 dbt 构件悄悄漂移，酿成两次静默事故
  （#813 容差地板 / #917 退货侧判别式）。**「引擎有」不等于「我们知道它有」——先问引擎是动作，不是知识。**

## 第 0 步：开工三查（顺序固定，缺一不开工）

1. **查正典判据**：读 `docs/data-platform-handbook.md` §1.1（三档）与 §1.1.1（E3 证成方法学）——
   别凭记忆答「引擎不支持」。
2. **查引擎能力目录**（这是**动作**，不是回忆）：`list_components`（按 kind 过滤）+
   `get_component_schema` 逐候选看真实字段。要给的是「真实字段名与取值」，不是「应该有个 X」。
3. **查既有替代清单**：`duckle/README.md` §7（原生可替代 / 半替代 / 仍需自建）；
   再看 `deploy/duckle/console/pipelines/` 里**同类节点有没有已经这么干过**（有先例就照抄，别重新发明）。

## 判停清单（按手头的事对号，有勾不掉的停在原地）

### ① 横向试遍同类

- [ ] 判「没有」之前，把**同一族的候选**都试过：对象存储要试到 `s3` / `minio` / `r2` / `b2` 这一组；
      取数要区分 `src.rest` / `src.postgres` / `src.<db>` / `code.*` 各自能到什么。
- [ ] **判停**：「试了一个不行」**不构成**能力缺口证据（正典 §1.1.1 明文）。

### ② 落三档（写进 PR 说明或 spec，不许含糊）

- [ ] **①引擎有 ⇒ 首选**：注明**怎么声明**（节点/字段）与**哪次实测**定的案。
- [ ] **②引擎有但未验 ⇒ 首选（未验）**：同段给出**最小验证动作**并挂 gate；验过才升 ①。
- [ ] **③结构性没有 ⇒ 归我方**：给**结构性理由**（引源码或上游自述）；「嫌麻烦」不算。
- [ ] **判停**：没有落档 = **不开工**。落不了档说明你还没查够。

### ③ 口径类工件：先去 dbt

- [ ] 若这件事是**业务规则 / 指标口径**（销售额、净额、退货冲减、成本…）：**不许在管线里实现**。
      按 `docs/architecture.md` §4.1 **B11**，口径只在 `dbt/` 定义一次，采集/对账/脚本/问数/BI
      **一律是消费者**（读物化结果）。
- [ ] **判停**：管线或脚本里出现口径原子 ⇒ `scripts/check-recon-caliber.mjs` 会红，CI 拦。

### ④ 登记缺口

- [ ] ②/③ 的结论写进正典 §1.7（逐源决策登记）或 `duckle/README.md` §7.4（未验清单）。
- [ ] **判停**：没登记 = 下一个人会把它当 ① 用。

## 红线（违反任何一条 = 不许合并）

1. **禁止把 ② 写成 ①**——没在本环境跑过就说「首选」。
2. **禁止把 ③ 写成 ②**——挂个 gate 拖着 = 永远不做。
3. **「试了一个不行」不构成能力缺口证据**——横向同类要试完，且必须真问过引擎目录。
4. **碰业务口径时，任何在 dbt 之外实现公式的提案直接驳回**（architecture §4.1 B11）。

## 边界

- 本 skill 管「**用什么实现**」；不管采集流程判停（那是 `collect-source`）与告警分工（那是 `data-monitor`）。
- 判据数值（阈值 / 容差 / 页大小 / 时效）只有正典与 spec 两个家，**本文件不出现数值**。
- 引擎版本会变（我们按「duckle 永远用最新版」走）：能力判断以**当前环境的真实目录**为准，
  不以本文件或任何笔记为准。
