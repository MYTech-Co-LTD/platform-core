## 2. 探针实证（2026-10-12，3120 活凭据）

### 2.1 方法（可复现）

- 通道：openship server exec（server `8281d598`）→ base64 包脚本 → **3120 console 容器内** `curl` 直打 `https://cloud.nhsoft.cn/agi/api/<接口>`。token 取容器 env `LEMENG_TOKEN`（明文，账套绑定），**不落任何输出/文档**。
- 为什么不信目录：能力目录 v4（`explore/探索乐檬-mcp/lemon-agi-catalog/_work/abilities_v4_latest.json`，10-05 拉）里 20 接口全部 `available=true`，但目录列的是**网关已知**能力，租户网关**未部署**的照样列出——「目录在场 ≠ 租户可调」。
- 判据：`"message":"接口不存在，请检查版本是否已更新"` = 不可用；业务层参数校验报文 = 可达；`code:0` + 真数据 = 硬证据。每接口至少两轮：空参数探路由 → 合法形状参数（page_size=1）探执行；「校验层可达」的再补第三轮升级成真数据/空集证据。

- **whs 族日期格式**：D05/D18/D19/D20 的 `date_start/date_end` 用 `yyyy-MM-dd` 报 `Cannot deserialize java.util.Date`，必须完整 `yyyy-MM-dd HH:mm:ss`（D04 ama 族同形收货成功）。

## 5. 语义定义设计（L1 落点与扩展）

### 5.1 落点

- 指标口径唯一事实源 = `dbt/semantics/l1_metrics.yml`（现状机制不动：`<源>:<业务域>:<指标>` 命名空间、definition 逐字口径、grain、owner、tier、逐指标 audit 复算）。
- 命名域枚举（新增）：`transfer` / `wholesale` / `expense` / `procure` / `inventory` / `finance` / `retail` / `ops`。
- **进 L1 的判据**：口径能被单一 SQL 表达、且能在声明 grain 上复算。两期对比/效应分解（02-05）/ROI（07-04）/候选配对（07-07）这类**多期或跨单据过程计算**属 L2（消费层/报表模型），spec 不逐项裁，实施计划里逐项过判据。

### 5.2 口径构件 = 每域 fct 表的标准列（不引入新机制）

客户附录的公共定义 R/C/G/E/N/P/A/L/Q/T 不做成新概念，落为**各域 marts 模型的标准列约定**（如 fct_transfer_out 聚合模型带 `r_net`/`c_cost`/`g_gross` 列；费用域带 `ep_payable`/`er_receivable`/`e_net` 列），指标 `expression` 引用构件列。「口径只定义一次」由「构件列只在 fct 定义一次 + 指标不重复算」保证。构件列约定表写进 `dbt/README.md`。

### 5.3 率类指标：l1_metrics.yml 增加 `ratio` 扩展

现状 L1 expression 只表达可加 sum。率类（毛利率/贡献率/占比/退货率/覆盖率…占 65 项约半）必须声明**不可加、上滚=重算**：

```yaml
- name: 'lemeng:transfer:gross_margin_rate'
  ratio: { numerator: 'sum(fct_transfer_out.g_gross)', denominator: 'sum(fct_transfer_out.r_net)' }
  # 有 ratio 时 expression 缺省为 num/den；零分母 → 不适用（不产 0）
```

同步面：静态门禁 `scripts/check-data-models.mjs`（L1 头注释明说改判据面必须同步 README 与门禁）+ 词表物化（`data.metrics` 消费侧要能区分可加/不可加）。**词表消费面对 ratio 的支持是未验项**（裁7）——W0 里验证，不支持则 L2 承接率类。

### 5.4 统一控制（客户附录「统一控制」条款 → 契约与 definition 模板）

采集侧（进各源契约断言）：审核单据 state=3（D19=2）+ 状态名回读；金额保留红字（不取绝对值）；null 不当 0（契约 nullable + qa 非空闸）。
语义侧（进指标 definition 模板必含条款）：先按源粒度聚合再连接（禁逐行连接放大）；零分母=不适用；缺关键数据不输出确定数值（tier=experimental 或不声明）。
