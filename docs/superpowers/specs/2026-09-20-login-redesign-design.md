# 登录页改版设计 —— 参考 Casdoor 的浅色分栏风格

- 日期：2026-09-20
- 状态：已评审（布局/文案来源/工程口径均经确认）
- 关联：Task 12 品牌契约、Task 14 企微扫码契约（本设计不改两者行为）

## 背景与动机

现行登录页（`apps/web/src/pages/Login.tsx`）是 `#f5f5f5` 纯色背景上一张 380px 白
Card：logo + 产品名 + Tabs + 表单，视觉单薄。用户参照公司 Casdoor 实例
（sso.hookflow.cn，v1.820）的登录页提出改版。

Casdoor 参照页的骨架：左右分栏——左侧约 2/3 深海军蓝品牌区（细网格纹理 + 中央
光晕 + 大号标语两行 + 副标语，左上角 logo + 产品名，左下版权/version），右侧白底
表单区（「登录」标题、带前置图标的灰色填充输入框、品牌蓝整宽按钮）。

**本次取其骨架、不取其深色**：用户选定「分栏但浅色左栏」方向——左侧浅色渐变
品牌区 + 深色字标语，整体比深色更像管理台登录页而非官网落地页。

## 目标 / 非目标

**目标**

1. 登录页视觉升级为浅色分栏布局，移动端折叠单列。
2. 品牌字段（logo / productName / primaryColor / background）在新布局里继续生效。
3. 行为零变化：登录流程、企微扫码、错误处理、跳转逻辑全部不动。

**非目标**

- 不改 branding 契约的接口形状（不加字段、不改路由）。
- 不做「忘记密码？」入口（无对应功能页，不做死链接）。
- 不做多语言 / 主题切换。
- 不动 console 内页设计。

## 视觉设计

### 桌面（≥768px）

```
┌──────────────────────────────────┬────────────────────┐
│ ▣ logo + productName（左上）      │                    │
│                                  │  欢迎登录           │
│                                  │  登录 {productName} │
│      安全、可信赖的                │  管理控制台         │
│      多租户管理平台               │                    │
│      （大标语，深灰粗体两行）       │  [账号密码|企微扫码] │
│                                  │  ┌──────────────┐  │
│   模块化控制台 · 租户隔离 · 订阅管理│  │ 👤 用户名     │  │
│   （副标语，灰色小字）             │  └──────────────┘  │
│                                  │  ┌──────────────┐  │
│   ── 品牌色短装饰线 + 圆点行       │  │ 🔒 密码       │  │
│                                  │  └──────────────┘  │
│                                  │  ┌──────────────┐  │
│                                  │  │   登  录     │  │
│                                  │  └──────────────┘  │
│ © 2026 productName               │                    │
└──────────────────────────────────┴────────────────────┘
```

- **左栏 ~55%**：浅色底（`#f7f9fc` → `#eef2f8` 微渐变）+ 细网格纹理（纯 CSS
  渐变绘制，不引图片资产）。左上 logo + 产品名；垂直居中大标语；标语下品牌色短
  装饰线 + 圆点行；左下版权 `© {年} {productName}`。
- **右栏 ~45%**：纯白底，与左栏以 1px 细边框分隔（不做浮起卡片）。表单区固定宽
  ~360px 垂直居中。

### 移动端（<768px）

折叠单列：顶部浅色品牌横幅（logo + productName + 单行大标语），下方白底表单。
副标语、装饰线、版权隐藏。

### 品牌接入

| 字段 | 消费位置 |
|---|---|
| `productName` | 左上品牌区、右栏副题、版权、`document.title`（现状保留） |
| `logo` | 左上品牌区（缺省只显示产品名） |
| `primaryColor` | 登录按钮（现有 `ConfigProvider` token 机制不动）、装饰线/圆点、大标语关键词着色 |
| `background` | 有值且 ≠ `'default'` 时作为**左栏底色**；否则默认浅渐变 |

**`background` 语义收窄**：从「整页背景」收窄为「品牌栏背景」。接口形状不动，
消费处注释改口径。现状 DB 默认 `'default'`，无租户配置过其他值（branding 无编辑
UI），无迁移需求。

### 文案（固定，不对接 branding）

- 大标语：`安全、可信赖的` / `多租户管理平台`（两行，「多租户管理平台」以
  primaryColor 着色）
- 副标语：`模块化控制台 · 租户隔离 · 订阅管理`

### 右栏表单

- 标题「欢迎登录」+ 副题 `登录 {productName} 管理控制台`。
- Tabs（账号密码登录 / 企业微信扫码）、错误 Alert、表单校验、加载 Spin 全部保留
  现有行为，只换皮：输入框加前置图标（`UserOutlined` / `LockOutlined`），按钮
  `size="large"`，输入框统一 40px 高。

## 工程实现

### 改动文件（纯前端，2 个）

| 文件 | 改动 |
|---|---|
| `apps/web/src/pages/Login.tsx` | 重写 render：Card → 分栏结构；**逻辑全部不动**（branding 拉取与兜底、`nextTarget` 防开放重定向、`queryError` 解析、Tabs 白名单兜底、企微 iframe + postMessage origin 校验、错误码文案） |
| `apps/web/src/pages/Login.module.css`（新增） | 分栏布局、网格纹理、渐变、`@media (max-width: 767px)` 折叠 |

CSS module 为项目首个，Vite 原生支持。复杂多层渐变与网格纹理塞 inline style 不可
维护，故引入；仍遵循「页面布局优先 inline/局部样式」的现有习惯，不建全局样式。

### 保持不变

- `ConfigProvider` primaryColor 注入机制。
- `PasswordForm` / `WecomQrTab` 行为契约（提交、postMessage、错误传递）；企微
  iframe 仅调整尺寸适配右栏宽度，行为不动。
- `api.ts` 的 `Branding` 类型与服务端路由。

## 测试

现有 `Login.test.tsx` 12 个用例的断言层（tab 名、productName 文本、登录按钮
`/登\s*录/`、错误文案、iframe src、postMessage 行为）与视觉重写正交，预期零改动
跑绿——设计时已逐条核对。

新增 1 个用例：branding 回传自定义 `background`（非 `'default'`）时左栏底色消费
到（守住收窄后的契约）。

## 验收清单

1. 本地起 server + web，浏览器（CDP）走查：默认品牌渲染、自定义
   primaryColor/background、企微 Tab iframe、错误 Alert（错密码一次）、`?next=`
   跳转、375px 视口折叠形态。
2. 波末全量门禁：web 单测 + typecheck + lint + build（与 CI 同款命令）。
3. `feat(web)` 先建 issue，PR 带 `Closes #N`，squash 合并。

## 已知边界

- 固定文案是权宜：后续租户要配标语时需扩展 branding 契约（加字段 + 迁移 + 路由），
  届时左栏文案区即消费点。
- 网格纹理纯 CSS 绘制，不同浏览器渲染差异可接受（装饰性元素，无功能语义）。
