**Goal:** `sync-data-plane.sh` 同步后清点检出树（lock 落地路径集为基准），孤儿默认报 `EXTRA`、`--prune` 删除——治「sync 只取件不删件 ⇒ 仓内删除的文件在真机永生」（#683 实证：x01_branch_region.csv 被当僵尸 seed 天天加载）。

**Architecture:** 方案 A（spec 已批）：prune 内建 sync。预期集在主循环顺手收集（lock 落地路径列，不二次解析 lock）；结论段 `find "$REPO" -type f` 全树枚举 vs 预期集，机器本地物 allowlist（POSIX `case` 函数）豁免。**作用域**：收窄到 manifest 目录型条目的落地子树（见「执行订正」#1；原稿此处写「只限 `${REPO}` 内」）。`--prune` 隐含完整同步（先同步后清理）；prune 在 revision 标记写完**之后**（「标记在 = 这套是全的」不变式不受干扰）。spec：`docs/superpowers/specs/2026-10-15-683-sync-prune-design.md`（其中 allowlist 双点订正已在计划阶段落盘，随 Task 3 提交）。

**Tech Stack:** POSIX sh（数据面机无 node；脚本无数组依赖）；测试沿用 `sync-data-plane.test.sh` 的假 curl + 真 sha256 + `tree_hash` 骨架；CI 接线进 `.github/workflows/ci.yml` 的 unit job（与既有五个 `.test.sh` 同址）。

## Global Constraints（每任务隐含）

- POSIX sh：`set -efu` + `set -f` 保持不动；计数器**不能**接在 `find | while` 管道里（子 shell 丢计数）——照抄现有 `done < file` 重定向模式。
- 现有输出契约字面量**全部不动**：`OK`/`DRIFT`/`SYNC_OK`/`SYNC_DRIFT`/`LOCK_FETCH_FAILED:`/`LOCK_SELFTEST_FAILED:`/`FETCH_FAILED:`/`REVISION_WRITE_FAILED:`。
- `--check` 退出码**仍只看 DRIFT**（EXTRA 是信息行；打断现有探活/审计调用方 = 违规）。
- prune 只删 `${REPO}` 内 `-type f`；**不删空目录**（spec 非目标）；`/opt` 不参与（共享目录无基准 + 同步器自身不在 manifest，枚举必自杀）。
- allowlist 写死脚本内（无配置面，YAGNI）；与 `deploy/data-plane-manifest.txt` 头注的「机器本地物」清单同源，两处同 PR 可改。
- 提交格式 `type(scope): subject`；PR 标题同格式；CHANGELOG 禁手写；**PR body 用 `Refs #683` 不用 Closes**——真机两步门（Task 5）过了才关 issue（既有惯例：#677 同样验收后手动关）。
- **CI CLEAN 才合并**；绝不手工补写截断 SHA（回 `git rev-parse` 逐字取）。
- shell 里 `$VAR` 紧跟中文字符一律写 `${VAR}`（本仓中文文案密，bash 3.2 会把中文吃进变量名）。
- Task 5 全程走 **openship MCP**（`post_system_servers_by_id_exec`，serverId `8281d598-af73-4d0b-99dd-bc8681fcc8bb` = 山海数据面机），**禁裸 SSH**；exec 对复杂命令间歇「Missing id」⇒ 命令保持简单、必要时拆多次，长任务改 custom job。
- 敏感值只写「在哪、怎么取」，不写明文；本脚本**无凭据原则**不变（匿名 raw 可读，别加 token 参数）。

```sh
# `find | audit_extras` 管道里——管道会把函数放进子 shell，计数器出不来（与主循环
# `done < file` 同一个坑、同一个解法）。
audit_extras() {
  _mode="$1"
  _extra=0
  while IFS= read -r _abs; do
    _rel=${_abs#"$REPO"/}
    if grep -Fqx -- "$_rel" "$_tmpdir/expected"; then
      continue
    fi
    if is_allowlisted "$_rel"; then
      continue
    fi
    _extra=$((_extra + 1))
    if [ "$_mode" = 'prune' ]; then
      if rm -f "$_abs"; then
        echo "PRUNED $_abs"
      else
        echo "PRUNE_FAILED: $_abs" >&2
        exit 1
      fi
    else
      echo "EXTRA $_abs"
    fi
  done
}

# 清点入口：全树枚举（**只限 `${REPO}` 内**——`/opt` 是共享目录，「不该有什么」没有基准；且本
# 脚本自己就不在 manifest，枚举它必把自己判成孤儿）+ 排序（输出确定，两次跑的清单可逐行比对）。
audit_checkout() {
  find "$REPO" -type f > "$_tmpdir/found"
  LC_ALL=C sort "$_tmpdir/found" > "$_tmpdir/found.sorted"
  audit_extras "$1" < "$_tmpdir/found.sorted"
}
```
