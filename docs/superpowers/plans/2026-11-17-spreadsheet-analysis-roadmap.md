# 类 Excel 分析报表 · 开发地图（2026-11-17）

> 定位：**不复制 Excel 的自由度，复制 Excel 的分析惯式。**
> 每个惯式 = 一个受治理的声明式原语；「Excel 公式」映射到 L2 指标 + 变更单治理（agent 提案 → 试算 → 人采纳），
> 不进报表规格。上级语境：`2026-11-13-report-platform-roadmap.md`（R3/R4 已完成，本图是其表格分析支线）。

## §0 可行性验证（2026-11-17，生产真实数据，账套 3120 / 2026-10 全月）

| 验证项 | 结果 |
|---|---|
| 词表 | 净销售额 / 订单数 / 零售毛利 / **零售毛利率**（不可加）全部已有 L1，均按 `branch_num` 分组 |
| 键对齐 | 4 度量 × 152 门店，**4×152/152 全覆盖**，零错位 |
| 耗时 | 单度量 10–72ms，4 度量串行 ≈125ms（≪ 3s p95 预算；R4 缓存/single-flight 再摊薄） |
| 缺口 | 「客单价」无独立指标 ⇒ 走 `submit_metric_change` 提 L2（治理通路已建成，正好首跑） |

## §1 红线（违反任何一条 = 不做）

1. 单元格级公式（`=A1*B1`）——口径治理红线（B11），计算列只能走 L2 提案；
2. 报表内 SQL / 合并单元格 / 自由画布 / 单元格写回——既有非目标；
3. 多度量合并是**纯展示级外连接**（无算术），每列各自的授权/掩码/审计仍由各自 `/query` 保证；
4. 无真实案例不做分组小计（W5 缓办）。

## §3 与宗旨指标的关系

- **N1 独立完成率**：模板「门店月度经营分析表」上线即计入观察；
- **N2 首次提案接受率**：lint 人话拒绝 + 工具描述更新，agent 拼错可自愈；
- **N4 口径修正率**：计算列强制走变更单 + 试算，不进报表原语；
- **N5 首屏 p95**：`/reports/query-stats` 直接观察多度量面板的 p95 回归。
