# 控制台 UI 约定（console-ui）

> 适用：`apps/web`（宿主壳、管理台）与各模块 `console/`（模块自助页）。
> 目的：用户从任何一页切到另一页，**版式、措辞、操作位置**都一致，不用重新学。
> 与 `docs/module-protocol.md`「二级菜单用路径前缀表达」配套：那里管菜单结构，这里管页面长相。

## 1. 菜单归属：先问「这是工作，还是账号」

| 内容 | 放哪 | 判据 |
|---|---|---|
| 业务功能（报表、指标、工单、通知规则…） | 左侧菜单，按模块分组 | 用户上班要做的事 |
| 平台管理（成员、角色、权限码、**数据范围**、订阅、集成、存储） | 左侧「管理」组 | 管理员才有的动作 |
| **账号级设置（个人 API Key、退出、身份信息）** | **右上头像下拉** | 只关乎「我自己」，与业务无关 |

**反例**：「个人 Key」曾放在左侧业务菜单第 2 位——用户会以为它是业务功能；实际是账号设置。
「数据范围」也曾放在「数据分析」下——它定义的是**谁能看哪些数据**，是权限动作，归「管理 → 角色与权限」。

**页面可以住在 A 模块、入口挂到 B**：manifest 声明 `menu: false`，宿主在别处给入口
（数据范围就是：页面/API 在 data 模块、`data:manage` 门不变，菜单入口在管理组）。

## 2. 页面骨架：一个头，一个内容区

所有页面统一用 `ConsolePage`（`apps/web/src/components/ConsolePage.tsx`）：

```
标题（h4）                 [右侧：主操作]
一句话说明（secondary，可省）
────────────────────────────────
内容（卡片 / 表格 / 表单）
```

- **模块页的标题由宿主渲染**（`ConsoleModulePage` 按 manifest `title` / `description`），
  模块组件**不要再自己画标题**——重复标题是当前最常见的「像两个人做的」来源。
- **主操作只有一个**，放标题右侧；次要动作（重置密码、删除）收进「更多」下拉或行内。
- 说明必须回答「这页能干什么 + 先做什么」，不写实现细节（不出现「schema / 管线 / 幂等」这类工程词）。

## 3. 列表页

- 一律：`Card` 包一张 `Table size="small"`，分页默认关闭（>50 行才开）。
- 有搜索价值的列表**必须**给搜索框（放在页头 `extra`，与主操作同排）：成员按用户名/显示名，
  权限码按键/名/持有人。
- 行内操作列宽 ≤ 190，**主操作在前**，危险操作（删除）用 `danger` + 二次确认。
- 空态必须写「下一步」：不是「暂无数据」，而是「还没有 X。先做 Y / 点这里」。
- 空态与搜索无结果要区分文案（搜索无结果时给「没有匹配『xx』的…」）。

## 4. 措辞

| 场景 | 用 | 不用 |
|---|---|---|
| 账号 | 成员 | 用户（与 Casdoor 实体混淆时例外，需括注） |
| 权限包 | 角色 | 角色管理 |
| 码级授权 | 权限码授权 | 角色与授权 |
| 数据可见范围 | 数据范围 | 数据权限 / scope（面向用户时） |
| 令牌 | API Key | 密钥 / token（文档里可以写 token） |

- 标题用名词（「成员」「数据范围」），按钮用动词（「新建成员」「保存」）。
- 一句说明 ≤ 60 字，超过就拆两页，别堆在一行里。

## 5. 状态与反馈

- 保存后顺序固定：**先刷新 → 再提示**（`message` 抛错会吞掉刷新，见 `Users.tsx` 的 issue #46 注释）。
- 任何写操作失败都要给出**可行动**的下一步（「去角色页建一个」而不是「操作失败」）。
- 危险动作二次确认，确认文案写清后果（「该操作不可恢复」）。
- 加载态：整页 `Spin`；表格 `loading`；导出/触发类按钮用 `loading` 锁重复点击。

## 6. 权限与显隐

- 入口显隐（菜单 / 按钮）= `session.scopes` 判定；**API 门卫才是真闸**，两者同语义、不互相替代。
- 页面上不承诺权限结果：写「需要 `data:manage`」这类码名只在报错里出现，说明文案用人话。
- 权限缺失时给「联系谁开通」，不要只说 403。

## 7. 一致性检查单（新页面提交前逐条过）

- [ ] 归属对（工作 / 管理 / 账号）
- [ ] 用 `ConsolePage`，没有自绘标题
- [ ] 一句话说明写了「能干什么 + 先做什么」
- [ ] 主操作唯一且在页头右侧
- [ ] 列表有搜索（有搜索价值时）、空态给下一步
- [ ] 措辞符合 §4，标题名词、按钮动词
- [ ] 保存顺序：先刷新再提示
- [ ] 权限入口与 API 门卫同语义，报错给人话
