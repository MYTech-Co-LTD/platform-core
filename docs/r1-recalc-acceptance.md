# R1 验收：日报复算清单（业务人员版）

> 目的：用**你自己的手**把报表上的数复算一遍，确认「页面上的数 = 系统算的数 = 能导出来对上的数」。
> 这是报表平台 R1（计算凭证与复算）的出口判据：**3 份真实日报、每人单份 ≤10 分钟、全部通过**。

## 谁来做、做多久

- **谁**：业务报表的日常使用者（不需要技术背景，会用浏览器和 Excel 即可）。
- **做多久**：每份报表约 5–10 分钟；共 3 份。
- **在哪**：后台 → 报表中心（需要能看这份报表的权限；看不到就先找管理员加）。

## 挑哪 3 份报表

每份都要满足（缺一条就换一份）：

1. 是**平台自绘**报表（打开后是卡片式页面，不是跳转到外部系统）；
2. 里面**至少有一张 KPI 卡**（大数字卡片，如「营业额」「订单数」）；
3. 已经**发布**过（标题旁有绿色「已发布 vX」标记）；
4. 选你**真的会用**的日报——验收的就是你每天要看的那几张。

## 复算六步（每份报表都走一遍）

### ① 记下页面上的数

打开报表，切换到你要验收的期间（近 7 天 / 本月均可），找到第一张 KPI 卡，
**把大数字抄进下面的记录表**。这就是「页面值」。

### ② 打开「计算过程」

点这张 KPI 卡上的**「计算过程」**按钮，会弹出一个抽屉。核对四行信息：

| 看什么 | 通过标准 |
|---|---|
| 口径 | 是你以为的那个指标（比如「净销售额」不是「含税销售额」） |
| 统计窗口 | 和页面右上角选的期间一致（起止日期逐字对） |
| 范围 | 是你要的门店/账套（没选错店） |
| 数据截至 | 有一个时间（比如「数据截至 …」）；没有这行说明新鲜度未知，记下来 |

### ③ 核对凭证值 = 页面值

抽屉里的「值」应该和步骤 ① 抄的页面值**一模一样**。
（它们是同一次查询算出来的；不一致 = 有问题，直接记下来报。）

### ④ 核对按日组成

抽屉下半部分有一张**按日小表**（营业日 / 值）。用计算器把「值」列加总：

- **加总 = 页面值** ⇒ 通过；
- 加总差一点（分位四舍五入内的零头）也算通过；差得多 ⇒ 记下来。

> 有的指标会显示「该指标不提供按日合计校验」——这是**说明**不是故障
> （比率类/不可加指标没有按日组成），这一项记「不适用」即可。

### ⑤ 导出 CSV 再算一遍

点**「下载按日 CSV」**，用 Excel 打开，对「值」列求和：

- **求和 = 页面值** ⇒ 「导出与页面数逐分一致」达成；
- 不一致 ⇒ 记下来（这是出口判据里最硬的一条）。

### ⑥（可选但建议）让系统解释差额

如果你手里有**自己从业务系统算的数**：填进「我算的是…」输入框，点**「对一下」**。
系统会给出差额，并尝试用按日组成解释「差额来自哪几天」。
解释得通 ⇒ 通过；解释不通/给了看不懂的说法 ⇒ 记下来（这正是要反馈的输入）。

> 「下载明细行 CSV」在你需要**逐笔核对**时用。如果提示「明细超过导出上限」，
> 缩小时间窗再导——这同样是说明，不是故障。

## 通过标准（整份报表）

- ①–⑤ 全部通过，且**总耗时 ≤10 分钟**；
- ⑥ 可选，但建议至少做一次。

**3 份全部通过 ⇒ R1 验收通过**；任何一步不过，把记录表那行标红并找数据团队。
